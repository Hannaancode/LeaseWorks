Dear TrueLinks AI team,

Thank you for shortlisting me. I have completed LeaseWorks, a full-stack prototype that connects a lease record and property issues in one unit workspace.

Solution repository: https://github.com/Hannaancode/LeaseWorks

Existing public repository: https://github.com/Hannaancode/RecoverML

The solution includes source-linked lease fields, all seven owner policy checks, photo observations and a draft work order. Owners can accept, reject or correct the proposals and review the audit history. Occupancy changes only after an explicit approval and a fresh availability check.

The README explains the approach, decisions, trade-offs, scaling limits and product improvements. The default demo runs without an API key using the permitted model stubs and clearly labelled sample data. A live text and vision adapter is also included with setup instructions. I have tested the application, the full owner browser workflow, and live text and vision inference. I also evaluated original public lease templates from Qatar, Dubai and Queensland, explicitly fictional contract details and four real equipment photographs. The repository includes actual results, earlier failures and the checks added in response.

In my first 30 days I would learn the current owner and facility workflows and ship one focused pilot that makes approvals easier to trust. My starting idea is an exception-first review flow with source evidence and clearer requests for missing information. I would measure review time and correction rate and use those findings to choose the next improvement. The repository includes the proposed 30-day plan.

RecoverML is an example of my existing work. It records ML artifact dependencies and hashes and restores earlier pipeline states under a storage budget. Its public repository includes code, tests, benchmark logs, plots and reproduction instructions.

I look forward to walking through the solution and discussing the product direction in person.
